One funny patch note for a bug in real life, written for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty. The program writes exactly that one line to `entry.txt`.

> v4.3.1: fixed a bug where the little toe, in the dark, located every table leg by direct impact.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/real-life-patch-notes-out python3 main.py
```

## Why the line works

The bug is specific and instantly recognisable: everyone has found a table leg with their little toe in the dark. The register is dry engineering — "located every table leg by direct impact" reads like a real fix note — and the wince is the punchline, so the reader laughs at a pain they know. At 96 characters there is no padding and no setup the joke does not need.
